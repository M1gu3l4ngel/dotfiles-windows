# 40-format

El estilo global del código: solo se aplica a los proyectos que no traen su propio
`.prettierrc` o `.editorconfig`. Es copia del de
[dotfiles-parrot](https://github.com/M1gu3l4ngel/dotfiles-parrot), para que las dos
máquinas formateen igual.

| Archivo | Qué es |
|---|---|
| `prettierrc.json` | Estilo de Prettier |
| `editorconfig` | Sangría y finales de línea de lo que Prettier no formatea |

Dónde se enlazan, qué configuración gana y cómo formatea VS Code al guardar:
[docs/formatting.es.md](../docs/formatting.es.md).
