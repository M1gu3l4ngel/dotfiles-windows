# 40-format

The global code style: it only applies to projects that bring no `.prettierrc` or
`.editorconfig` of their own. A copy of the one in
[dotfiles-parrot](https://github.com/M1gu3l4ngel/dotfiles-parrot), so both
machines format the same way.

| File | What it is |
|---|---|
| `prettierrc.json` | Prettier style |
| `editorconfig` | Indentation and line endings for what Prettier does not format |

Where they are linked, which configuration wins and how VS Code formats on save:
[docs/formatting.md](../docs/formatting.md).
