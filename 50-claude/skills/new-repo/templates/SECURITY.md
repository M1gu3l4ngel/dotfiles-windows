# Security

## Supported versions

Only <the latest release | the latest commit on `main`> receives fixes. Each release is listed
in [`CHANGELOG.md`](CHANGELOG.md).

## Report a vulnerability

Do not open a public issue. Report it privately in one of these ways:

1. **On GitHub:** in this repository, open **Security**, then **Report a vulnerability**, and
   fill in the form.
2. **By email:** <only with an organization address: write to `<support address>` with the
   subject `Security: <repo>`. Without one, remove this item.>

Include what is affected (<the pieces of this repository>), the steps to reproduce it and the
impact you see. You get an answer that confirms the report, and you are kept informed until it
is fixed. Once the fix is released, the report is published with credit to you, unless you
prefer otherwise.

## Scope

- **In scope:** <what this repository runs or publishes>, and anything in it that could leak a
  secret or run code a user did not expect.
- **Out of scope:** vulnerabilities in <third-party tools> themselves, which go to their own
  projects.
